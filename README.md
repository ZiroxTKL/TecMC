# TecMC

TecMC is a custom Minecraft Forge 1.20.1 server/modpack project focused on RPG adventure, exploration, lore, custom quests, bosses, dimensions and lightweight Create-based engineering.

## Core identity

- Minecraft 1.20.1
- Forge
- Java 17
- RPG adventure
- Custom lore and quests
- Bosses and dimensions
- BetterMC / Cisco Fantasy Medieval inspired
- Difficult, but not unfair
- Create is used for lightweight engineering, realism and functional decoration

## Mod selection filter

Every mod must answer at least one of these:

- Does it add adventure?
- Does it add progression?
- Does it add ambience?
- Does it add necessary QoL?
- Does it improve performance?
- Does it break balance or progression?
- Does it increase technical, compatibility or worldgen risk?

## Project rules

- Worldgen mods must be decided before the official world is created.
- No world-breaking generation mods after release.
- Create is not the main focus.
- No massive factory gameplay.
- No free chunk loaders.
- Blue Skies is planned as a future expansion.
- Config changes must be tested and documented.

## Project documentation

Main documentation files:

- `docs/changelog.md`: project phase history and decision log.
- `docs/modlist.md`: current mod stack organized by category and side.
- `docs/config_changes.md`: important server configuration decisions.
- `docs/backup_policy.md`: backup rules and restoration validation.
- `docs/performance_tests.md`: TPS/MSPT testing plan and performance evidence.
- `docs/progression_plan.md`: progression, quests and world unlock planning.
- `docs/npc_trades.md`: NPC trade planning and balancing.

## Workflow

- CurseForge: mod management and dependencies.
- VSCode: configs, quests, docs and server files.
- GitHub: version control for configs and documentation.
